SIRE — Sistema Integral de Respuesta ante Emergencias

Inventario de pantallas de la aplicación ciudadana (Android). Las maquetas reproducen la interfaz implementada: Material 3 en tema oscuro, generado a partir del color semilla rojo emergencia, con los datos reales registrados durante las pruebas de campo.

Sistema de diseño

La paleta completa se deriva de un único color semilla mediante el algoritmo de Material 3, lo que garantiza contraste accesible en toda la interfaz. El rojo se reserva para la acción de emergencia; nada más compite con él.
